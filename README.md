# تطبيق AnimePaint - نسخة ماريا (AnimePaint - Maria Edition)

تطبيق رسم وتلوين متطور واحترافي مصمم للويب وأجهزة سطح المكتب، وهو نسخة مخصصة ومعربة بالكامل من محرك الرسم مفتوح المصدر Klecks، وتتميز بواجهة كاملة تدعم اتجاه الكتابة من اليمين إلى اليسار (RTL) بالإضافة إلى إصدارات تشغيل مباشرة لنظام ويندوز دون الحاجة لتثبيت أي متطلبات إضافية.

---

## الميزات الأساسية للبرنامج
* **نظام الطبقات المتكامل**: دعم إضافة وحذف وترتيب ودمج الطبقات، وتعديل قيم الشفافية وأنماط المزج (Blend Modes).
* **فرش رسم احترافية**: مجموعة متنوعة من الفرش تشمل قلم الرسم، أداة المزج، الرسم التخطيطي، بكسل آرت، والفرش الكيميائية المتقدمة.
* **دعم حساسية الضغط والقلم**: توافق كامل مع الألواح الرقمية (Drawing Tablets) مع ميزة التنعيم التلقائي للخطوط (Stabilizer).
* **أدوات معالجة قوية**: أدوات التحديد، دلو الطلاء، إدراج النصوص والخطوط العربية، الأشكال الهندسية، وتدرجات الألوان.
* **فلاتر مدعومة بـ WebGL**: مؤثرات متطورة لمعالجة الصور تشمل التشويش الذكي، التشويه البصري، ضبط المنحنيات، وتصفية الخطوط الأساسية (Lineart Extraction).
* **تعريب كامل ومحاذاة RTL**: تعريب شامل لكافة فلاتر وأدوات وقوائم البرنامج مع دعم كامل للاتجاه من اليمين إلى اليسار لضمان تجربة مستخدم سلسة باللغة العربية.
* **واجهة مستخدم محسنة**: ألوان متناسقة داكنة، تصميم مريح للعين، وإمكانية تعديل عناصر الواجهة لتناسب الأجهزة الضعيفة.

---

## التقنيات المستخدمة
* **لغة البرمجة**: TypeScript و JavaScript (ES6+).
* **محرك الواجهات والتنسيق**: SCSS / Vanilla CSS مع دعم RTL ومحاذاة ذكية للمكونات.
* **إدارة الحزم والبناء**: Parcel Bundler لتجميع الكود وتحسين الأداء.
* **إطار عمل سطح المكتب**: Electron لربط كود الويب ببيئة تشغيل سطح المكتب وتوفير سرعة استجابة فائقة.
* **مسرع الرسوميات**: WebGL لمعالجة الفلاتر والمؤثرات البصرية المعقدة بسرعة فائقة بالاعتماد على كارت الشاشة.
* **قاذف التشغيل الذاتي**: مبني بلغة C# (.NET) لتقديم ملف تنفيذي واحد مدمج ذاتياً يضغط ويشغل بيئة العمل بسرعة فائقة دون الحاجة للتثبيت.

## دليل التحميل والتشغيل المباشر لسطح المكتب (ويندوز)
لا تحتاج إلى تثبيت أي برامج أو حزم برمجية لتشغيل تطبيق AnimePaint على جهازك. يمكنك تحميل ملف التشغيل المباشر كالتالي:

1. توجه إلى صفحة **الإصدارات (Releases)** في هذا المستودع على GitHub (تجدها في القائمة الجانبية اليمنى أو من خلال تبويب Releases).
2. ابحث عن الإصدار الأخير (النسخة المستقرة الأولى).
3. في قسم **الأصول (Assets)** أسفل الإصدار، اضغط على الرابط لتحميل الملف التنفيذي المباشر:
   `AnimePaint_Maria_Core_Final.exe`
4. بعد اكتمال التحميل، انقل الملف إلى أي مكان تريده على جهازك (مثل سطح المكتب)، واضغط عليه مرتين للتشغيل مباشرة.

*ملاحظة: عند التشغيل للمرة الأولى، سيقوم البرنامج بتهيئة الملفات اللازمة تلقائياً في ثوانٍ معدودة ثم فتح واجهة الرسم.*

## تشغيل المشروع محلياً للتطوير (للمطورين)

إذا كنت ترغب في تشغيل المشروع في بيئة التطوير المحلية وتعديل الكود، يرجى اتباع الخطوات التالية:

### المتطلبات الأساسية
* تثبيت بيئة Node.js (الإصدار 16 أو أحدث).
* تثبيت مدير الحزم npm.

### الخطوات
1. قم بتهيئة وتثبيت الحزم التابعة للمشروع:
   ```bash
   npm ci
   ```
2. قم ببناء ملفات اللغات المدعومة:
   ```bash
   npm run lang:build
   ```
3. لتشغيل خادم التطوير المحلي للويب (بث حي للتعديلات):
   ```bash
   npm run start
   ```
   بعد التشغيل، يمكنك فتح المتصفح على العنوان: `http://localhost:1234`

4. لتشغيل نسخة سطح المكتب (Electron) في بيئة التطوير:
   ```bash
   npm run electron
   ```

5. لبناء حزمة الويب النهائية للإنتاج داخل مجلد `/dist/`:
   ```bash
   npm run build
   ```

6. لبناء وتغليف النسخة التنفيذية المغلفة بالكامل لويندوز:
   ```bash
   node build_pack.js
   ```
